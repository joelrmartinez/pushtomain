The idea

Deepgram sells two ways at once: a developer console where anyone can start on credits, and an enterprise team that closes contact centers, drive-thrus, and voice agent platforms. The hard GTM engineering question sits between them: which teams should a human talk to, and which should the product keep nurturing?

The radar answers it from the outside in. It looks for teams shipping voice agents in public, scores how much they look like Deepgram's best customers, and hands each one to the right owner with the evidence attached.

What I built

Collectors pull organisation-owned repos from GitHub search, Show HN and Launch HN posts from the Algolia API, and voice-related roles from a curated list of public job boards. Hits merge by domain, then regex tags mark intent: mentions Deepgram, builds voice agents, runs on LiveKit, Pipecat, Vapi, or Twilio, uses a competitor's speech-to-text, sells into contact center, restaurants, or healthcare.

The score is a plain formula out of 100: intent + displacement + traction + corroboration + vertical, with every part exported so a rep can see why. Routing is an ordered rule list. Competitors and platform partners never auto-route. APAC locations and ccTLDs go to the Singapore team. AE-level scores without a verified domain go to a human first.

The only AI step is an optional one-line "why now" note per account. It cannot move a score or a route. Config lives in a YAML file with env overrides, secrets live in env only, logs are structured JSON, and CI runs ruff, mypy, and pytest on three Python versions.

The receipt

  • First real run: Bland, Assort Health, Decagon, and Parloa routed to an AE on voice-heavy hiring; LiveKit, Pipecat, and Stream flagged for partnerships instead of sales.
  • The sample output, with scores broken into parts and a link to the source signal for each account, is committed next to the code.
  • What it would need inside Deepgram: Salesforce accounts, console usage, and Ordway or Metronome billing joined in, so "already a customer" and "usage spiking" become the strongest signals. The public view is the starting point, not the answer.
